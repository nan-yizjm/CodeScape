# CodeScape 第一版开发留档

留档日期：2026-10-14。版本：`v0.1.0-p0`。应用版本：`0.1.0`。Windows x64 构建：`20261013T182645Z`。

这是 P0 最终开发候选的预发布留档，保存源码、中文开发提交、需求与设计、检查及验收记录，并提供对应安装包和便携包。当前 35/36 项验收已验证；AC-29 开发复核通过，最后用户理解验收待确认。

## 已交付能力

- 本地目录和公开 Git 项目导入、范围预览、独立只读源码快照及 Python、TypeScript、C/C++ 静态索引。
- AI 分批架构分析、受控源码补读、任务暂停与检查点恢复、全局概览及预生成函数讲解。
- 逐层架构探索、两层父子展示、收起返回上一级、同级模块切换、依赖聚合、源码证据和全屏阅读。
- 学习状态与视口保存、项目重扫与版本迁移、项目删除、当前层级 SVG 导出。
- DeepSeek 与兼容接口配置、Windows DPAPI 密钥保存、真实请求与用量账本。
- Windows 独立启动、单实例复用、安装、跨构建升级、数据兼容校验和卸载保留数据。

## 验证与实际边界

- 后端 476 项、前端 36 项检查通过；Ruff、TypeScript 与生产构建通过。固定响应检查与真实模型评测分开记录。
- 最终包在当前 Windows 11 开发机完成独立运行、运行中升级、学习保留、损坏数据拒绝和卸载保留数据验证；无凭据隔离环境完成 124 个已有源码批次的检查点恢复验证，未发出模型请求。
- Flask 完整约定范围已正式发布并完成用途、职责、核心协作及范围对照复核。Hiredis 与 spdlog 的新缩小范围已发布，Zod 保留原缩小范围真实复核。
- Hiredis、spdlog、Zod 的完整范围任务仍暂停；未将保存的检查点当成完整架构，也未宣称四仓库全部讲解质量通过。
- 最后一项用户验收需确认：能解释代表性项目是什么、主要部分做什么，并找到至少一条有源码证据的协作。
- 用户已免除本轮干净 Windows 10/11 测试矩阵；仍不声称这些环境或跨正式版本已经实测。安装包未签名。
- 支持与解析缺口保留在界面和验收记录中。程序不执行被导入项目的代码、安装、构建或测试。

详细状态见 [P0 验收追踪](../reports/p0/P0验收追踪.md)，实现与实测过程见 [开发与验收记录](../reports/p0/开发与验收记录.md)。
