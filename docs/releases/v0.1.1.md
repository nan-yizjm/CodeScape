# CodeScape 0.1.1：新版界面与桌面入口

发布日期：2026-10-17。适用于 Windows x64。本次基于已通过用户验收的 P0 功能，交付新的界面和应用图标，没有新增 P1 业务功能。

## 使用变化

- 项目库采用浅色简约布局，统计、项目卡片和操作入口更清晰。
- 工作区顶部更紧凑，1440×1000 示例中画布高度增加约 156px，统计与操作仍完整保留。
- 模块配色、详情、源码阅读、弹窗、焦点与短过渡统一；窄屏保留统计并支持滚动。
- 使用黑白层叠结构图标；安装时勾选“创建桌面快捷方式”，之后双击“CodeScape 源境”即可启动。

项目导入、模型配置、分批分析、两层架构探索、依赖证据、学习记录、源码阅读与 SVG 导出沿用原有行为。安装和卸载均保留应用数据；用户原项目不被修改。

## 下载与安装

[GitHub 版本下载](https://github.com/nan-yizjm/CodeScape/releases/tag/v0.1.1)。常规使用选择 `CodeScape-0.1.1-Windows-x64-Setup.exe`，便携使用选择 `CodeScape-0.1.1-Windows-x64-Portable.zip`，解压后运行 `CodeScape.exe`。便携与安装版本默认使用同一当前用户数据目录；同一目录由单实例机制保护。

安装包未签名，不宣称获得 Windows SmartScreen 信任。本轮在现有 Windows 11 开发机验证，不声称完成干净 Windows 10/11 测试矩阵。固定响应回归与安装验证不代表新增的真实模型质量评测；本轮不请求模型。

前端验收及同尺寸截图见 [视觉优化与验收](../reports/frontend/视觉优化与验收.md)。最终构建信息、SHA-256 和安装实测见 [新版发布与安装验收](../reports/frontend/新版发布与安装验收.md)。原 [P0 第一版留档](v0.1.0-p0.md) 的标签与制品保持。
