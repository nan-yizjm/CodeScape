# CodeScape 0.2.0

本版补齐基础开发范围：本地学习辅助、人工架构调整、双项目学习与历史变化。沿用 0.1.1 浅色界面和桌面图标，不增加普通阅读的模型费用。

## 新增功能

- **找代码、记理解**：Ctrl+K 搜索模块、函数、路径、讲解与笔记，跨层定位；详情中写纯文本笔记，自动保存。保存失败保留草稿，冲突需明确合并；阅读指引提供理由和源码依据，不把推荐起点当作程序入口。
- **修正架构**：修改名称和职责、拆分、合并、调整归属，预览后保存；可撤销、重做或恢复原始架构。原始 AI 结果独立保留，关系仍来自源码证据。重新分析后可靠匹配的修改和笔记迁移，无法确认的集中提示。
- **两边一起看**：项目库打开项目后，选择“对比学习”；两侧可独立展开、阅读、记笔记和保存进度，拖动中间分隔条调宽度。窄屏切换左右侧，不作自动配对或 AI 对比总结。
- **看历史与更新**：“版本与变化”保留最近五个成功版本（含当前），固定版本额外保留。可只读查看历史源码、比较函数实现、归属和确认调用变化；阅读租约与待复核修改保护旧版。源码发生变化只提醒，需自行发起分析。远程 Git 仅主动检查时联网。

## 安装与升级

使用 Windows x64 安装包，勾选“创建桌面快捷方式”，之后双击“CodeScape 源境”。便携包解压后运行 CodeScape.exe；两种方式默认使用当前用户的应用数据目录。

从 0.1.1 升级时先正常保存退出。数据库从 cs_0003 升至 cs_0004，升级前自动备份；项目、学习记录、任务检查点及 DPAPI 凭据保留。历史列表仅开放记录与快照完整的成功版本，不补造旧历史。项目永久删除同时删除其笔记和历史，原始源码不受影响。卸载程序保留应用数据。

## 明确边界

本轮不发送真实模型请求；离线固定响应、人工样例和静态解析测试不能证明新模型质量。程序流程图经 Python、TypeScript 样例验证后放弃：仅窄范围直线调用可靠，与已有调用图重复，未加入入口或半成品按钮。

安装包未签名，Windows 可能显示发布者提示。开发机检查不替代未实测的干净 Windows 10/11 矩阵。源码快照与说明仍有静态分析局限，不执行被分析项目。
