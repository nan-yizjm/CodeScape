# CodeScape 应用图标

设计日期：2026-10-17。按用户要求设计，采用深色圆角底与白色层叠结构，融入字母 C，表达从项目全景逐层深入源码。视觉稿使用 imagegen 生成，未使用项目源码或模型服务凭据。

原始设计稿：[codescape-icon-v1.png](codescape-icon-v1.png)。Windows 成品：[codescape.ico](../../packaging/codescape.ico)，保留透明通道，包含 16、24、32、48、64、128、256px 七种尺寸。导出仅调整尺寸和文件格式，不改变图形。

程序通过 PyInstaller 内嵌图标，安装器通过 Inno Setup 使用同一 ICO；桌面与开始菜单快捷方式继承程序图标。界面导航的现有矢量符号保持本轮视觉验收版本。
