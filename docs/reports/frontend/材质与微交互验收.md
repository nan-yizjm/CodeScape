# 前端材质与微交互重构

日期：2026-10-23。分支：`codex/frontend-material-system`。基于 0.2.0 完整功能，按本轮十条视觉规则调整项目库、架构工作区、详情、源码、学习工具、对比页面和弹窗。

## 十条规则的实现

| 规则 | 实现与边界 |
|---|---|
| 去装饰边框 | 暖白 `#f5f5f3` / `#fcfcfb` 与相邻微明度表面区分层次。暗色采用 `#0b0b0a` / `#151515` / `#1a1a19` / `#20201e`。卡片、表单、弹窗、节点取消装饰描边；依赖线和键盘焦点仍保留。无纯黑展示色。 |
| 输入聚焦 | 普通模式不使用 outline；内圈 1px 与外圈 3px 双环 box-shadow，键盘及鼠标聚焦一致。系统强制高对比模式保留系统焦点标记，避免阴影被系统移除后无法定位。 |
| 暗色字重 | 跟随系统外观，400/500/600/650/700 分别变为 360/460/560/610/660。实际字形可用的细分字重取决于系统字体，不下载字体。 |
| 逐字呈现 | 新到达的短反馈每个字素 90ms，从 blur(6px) 到清晰，间隔 30ms，曲线 `cubic-bezier(.215,.61,.355,1)`。组合字符与 emoji 不拆散；长文、历史内容、减少动画偏好直接显示。模型响应仍在完成校验后发布，不将现有讲解伪装成实时生成。 |
| 行内图标 | `vertical-align: -.125em`；浏览器在 14px 文字中计算为 -1.75px。 |
| 数字防抖 | 全局及表单统一 `tabular-nums`，统计数字和行号稳定。 |
| 平滑折叠 | 证据、范围说明、用量、任务历史、导入预览、架构编辑和差异列表复用 Grid `0fr → 1fr`，不测量高度。折叠内容保持挂载并使用 inert / aria-hidden，保留展开状态持久化。 |
| 防孤字 | 正文使用 `text-wrap: pretty`；窄屏短统计标签额外使用 balance。 |
| 动效性格 | 单位质量解析弹簧：握持条与主动视角对齐采用 1200/80 过阻尼，复制成功对勾采用 380/18 欠阻尼。拖动面板宽度与画布平移直接跟手，尺寸不追加惯性；握持反馈零回弹。 |
| 反馈自熄 | 签名、所选源码片段复制成功后保持 2.5 秒，再以 160ms 淡出恢复；拒绝剪贴板权限时明确反馈，不显示假成功，可重试或手动复制。 |

将用户输入中的 `#ObOb0a`、`Ofr`、`355` 分别按有效 CSS `#0b0b0a`、`0fr`、`.355` 实现。

## 结构与兼容

- `theme.css` 集中管理浅深色、文字、阴影、字重和时间令牌，`style.css` 统一页面与响应式排布。
- `palette.ts` 为画布与 SVG 提供同一套颜色；SVG 固定采用可独立阅读的浅色。节点尺寸、端口坐标、依赖证据与路由算法不变。
- `InteractionPrimitives.tsx` / `interactions.css` 管理折叠、短反馈和复制；`DragHandle.tsx` 为面板调宽增加 pointer capture、取消收尾与键盘操作。
- CodeMirror 语法和目标行高亮支持暗色；切换系统主题不重建编辑器，不丢失阅读位置。
- 减少动画时取消逐字和弹簧；减少透光或不支持 backdrop-filter 时仍有实体背景。
- 没有新增依赖，没有改后端接口、数据库或原始 AI 架构。用户参考方案、已有标签和正式安装制品保持原样。本轮更新源码运行版本，没有重新制作安装包。

## 检查结果

- TypeScript 检查、53 项前端测试、497 项后端测试与生产构建通过。构建保留已有的源码阅读器分块大于 500kB 提示；后端保留现有 Starlette TestClient 弃用提示。
- 320 / 390 / 800 / 1200 / 1440 / 1920px 的项目库、工作区、设置共 18 个组合未发现页面横向溢出；补查短屏源码、笔记、双项目、长文字及缩放。
- 浅深色正常状态文字与语义提示令牌最低对比度分别为 4.657:1 / 5.982:1。六组画布文字均 ≥4.5:1；实测样例源码文字在高亮区亦可辨认。
- 15 组核心浏览器检查通过：模块展开、同级恢复、收起保留依赖、全屏与 Esc、搜索跨层定位、笔记与学习状态刷新恢复、只读源码高亮、详情返回、架构编辑折叠与预览、版本历史、阅读指引、对比两侧隔离及窄屏切换。
- 11 组复制/折叠/短反馈检查通过。复制约 2513ms 开始淡出，约 2682ms 恢复；包含失败重试、源码内容一致、Enter / Space、不可见内容不可聚焦和减少动画。
- 10 组拖拽检查通过：实际鼠标移动 90px 对应面板宽度改变 90px；Home / End、方向键、pointercancel、减少动画及卸载收尾正常。
- SVG 实际下载核对：5 节点、4 条依赖及几何保持，颜色与画布共享浅色定义。

首轮发现短视口顶部信息挤压源码至 0px，已将窄屏详情改为覆盖工作区的面板；390×700 的源码区恢复至约 463px，并兼顾全屏与内嵌对比窗口。320px 统计标签孤字也已修正。多浏览器同时操作同一人工项目曾触发一次工作区修订冲突，应用正确提示并发冲突，后续检查分开执行。
