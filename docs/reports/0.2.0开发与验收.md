# CodeScape 0.2.0 开发与验收

开始日期：2026-10-17。实施分支：`codex/p1-completion`。依据用户确认的基础开发收尾计划：学习辅助、人工架构调整、双项目和历史对比；流程图单独验证，可放弃。其余 P1 不在本轮范围。

约定：本地搜索与指引；最近五个成功版本含当前，固定版本额外保留；人工修改与笔记可靠匹配自动迁移，歧义待确认；不增加自定义关系。保留 P0 与 0.1.1 标签及制品，不执行原项目，不修改原始源码，不新增真实模型请求。

本轮从版本化数据与工作区隔离开始。阶段实现、实测结果和真实边界按事实追加，未通过检查不记作交付完成。

## 第一阶段：版本化数据与学习工具

新增 cs_0004 迁移及工作区文档表，笔记、人工架构与操作历史、版本固定及独立视图分别保存；原始架构不被编辑覆盖。历史详情和源码使用带版本的独立接口，旧临时源码接口仍保留原过期规则。保留最近五版和固定版，读取租约保护正在阅读的快照；共享快照不会因删除一个版本而被误删。

接入本地内容搜索、源码定位、阅读建议、纯文本笔记及修订冲突保护，人工改名、说明、拆分、合并、归属调整与预览/撤销/重做；双项目复用同源独立探索器，各侧使用独立保存键和读取租约。窄屏采用左右切换，对比顶部信息折叠后仍显示统计、样例来源及保存状态。

新增13项后端场景已通过。首次全量检查488项通过、1项失败：旧测试要求立即清理旧版本，与新的五版保留需求冲突；改为验证旧接口过期、历史接口可读及显式删除清理，没有删除旧的版本隔离断言。修订后的版本与工作区20项检查通过，最终全量回归待后续完成。

Playwright隔离人工样例已验证搜索跳至正确函数、笔记自动保存、双侧层级隔离、笔记归属隔离、学习状态隔离、宽度调整、刷新恢复与窄屏切换。发现窄列顶部占用过多，已压缩并保留信息展开入口。截图保存在`output/playwright/p1/`，当前不是最终交付记录。本轮未发送模型请求。

工具记录：组合式后台启动和浏览器命令被自动审批以“blocked by policy”拦截，未给出更详细原因；改用受控终端会话启动隔离预览并确认HTTP就绪，随后独立Playwright入口成功。没有使用用户数据目录或执行样例代码。

## 第二阶段：迁移、并发与架构操作复核

笔记首次创建也按对象做并发保护；目标已有笔记时必须显式合并，两个修订号在同一事务校验。失败草稿仍可在笔记列表选择目标恢复。版本发布事务迁移可靠笔记关联、人工架构及各侧工作区，函数学习状态仍按原有严格身份和实现指纹迁移。部分修改不能匹配时保留可靠文字调整，其余明确待复核；含待复核修改的旧版本暂时保护，用户确认或放弃后解除。

架构阅读分组优先参考已确认协作，未连接部分按源码邻近组织，避免原先按随机ID切块；较大范围先作有界的源码导航，分组明确标识为阅读辅助，不冒充AI职责结论。缓存只复用相同结构及调用证据，学习状态变化不重复计算分组。新增用例确认协作紧密的成员同组、输入次序不改变组员及调用证据完整。

Playwright七组架构实际操作通过：预览后保存、改名与职责说明、撤销和重做、拆分不丢函数、两层返回上一级、合并清除冗余单子包装、恢复原始架构。相关后端精选检查58项通过；后续新增修订后版本/工作区/模式检查33项通过。TypeScript及前端37项通过，最终全量回归和安装升级仍待完成。

流程图原型对Python、TypeScript各六类静态样例做验证，仅直线调用形成候选顺序，分支、递归、异步、动态绑定及嵌套实参均拒绝推测。依据用户允许放弃的条款，本轮不纳入生产流程图，因为有效范围与已有调用图重合，尚不能可靠表达程序行为。未执行样例，未请求模型，结果见[p1/流程图可行性验证](p1/流程图可行性验证.json)。

最终功能修订后，Ruff、TypeScript、前端38项、后端496项及生产构建通过。后端唯一警告为现有Starlette/httpx弃用提示，构建仍提示既有源码阅读器大于500kB，不影响成功状态。本轮没有真实模型请求；固定响应只验证数据与行为，不构成模型语义质量证据。

隔离人工样例Playwright复核通过：阅读建议的全局/职责/协作/未掌握候选及限制说明；Esc关闭焦点恢复；模拟503保存失败不丢草稿、显式重试合并、刷新后正文恢复；历史固定/取消固定、固定时不能删除、差异摘要与旧版架构只读；历史分析、授权和架构编辑均禁用。并发首次创建、修订冲突、待重新关联、可靠及部分迁移、五版保留、共享快照、清理失败和损坏快照由后端用例覆盖。

人工图规模验证覆盖50稀疏、200密集、1000稀疏及1000密集，全部无布局回退，节点数据与全量SVG保留。大图采用视口绘制，不承诺千节点同时可读；阅读分组用于逐步浏览。具体本机耗时及输出体积见[p1/人工图规模验证](p1/人工图规模验证.json)，单机测量不能代表所有硬件性能。
