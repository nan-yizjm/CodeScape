## FR / NFR 的覆盖范围

全部 FR 的设计与 AC 映射保持在 [测试计划](../../CodeScape_Test_Plan.md) 第 5 节。本轮测试文件覆盖导入、项目库、分析/关系/补读、模块与函数投影、阅读面板、学习/会话、任务/候选/发布、快照/迁移、凭据/本地服务与 SVG；没有将测试数量等同于全部子要求通过。与真实用途和职责相关的 FR-ANA-01/05、FR-MAP-01/03/05 仍受 AC-06/29/30/31 的质量验收限制。

| 非功能项 | 当前证据/限制 |
|---|---|
| NFR-01 / 03 | 自带 Python/Node/Git/Clang 声明与许可证；独立开发机安装实测，干净 Windows 10/11 待测 |
| NFR-02 | 用户界面、提交、开发和验收记录为中文；真实源码名称保留；中文 SVG 和宏位置实测 |
| NFR-04 | DPAPI、鉴权/CSRF/Host、授权/范围、路径/VFS、删除反例已测；密钥没有进入 Git、报告或命令参数 |
| NFR-05 | 确定边有位置、作用域、目标和来源校验；代表性工程逐条语义/主要协作质量仍待核对 |
| NFR-06 | 普通阅读、证据/讲解、学习保存不请求模型；系统断网全新浏览器流程待补测 |
| NFR-07 | 发布、检查点、队列、幂等、迁移、删除、资源加载与原生解析故障分别验证；跨事务幂等存在需状态核对的崩溃窗口 |
| NFR-08 | 四仓库静态实测与 50/200/1000 人工图梯度已记录；单次浏览器测量不是统计性能保证，C++ 缺口及超时回退明确可见 |
| NFR-09 | DTO 与保存产物兼容字段、流水线版本、旧结果本地读取已测；不承诺覆盖所有语言动态行为或跨语言机制 |
| NFR-10 | 请求账本逐次记录；NULL/未知不记零，缺价格不编造费用；真实模型与固定响应分别记录 |

## 发布前仍需落实

1. 四个固定公开工程的真实 AI 质量评测、源码基线和范围对照。此前上传授权仅限三个预置文件；扩展询问已发出，未授权的工程没有发送至 DeepSeek。
2. 干净 Windows 10/11 安装、跨正式版本升级、真实休眠与系统断网重开实测。开发机现有测试不能代替这些结果。
3. 用户最终验收用途说明、职责划分、至少一条核心协作与整体可读性。真实模型的自然语言说明仍需检查，不将引用有效视为解释必然正确。

所有安装包继续标记未签名预发布。历史报告记录当时版本；后续构建不会使以前未运行的环境自动通过。
