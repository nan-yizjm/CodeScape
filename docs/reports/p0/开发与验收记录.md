## 公开 Git 导入、范围预览与静态失败恢复

- 本地目录与公开 HTTP/HTTPS Git URL 共用“扫描预览→确认导入”流程。远程仅取默认分支，保存实际 Commit；不检出工作树、不运行 hooks/filter、不下载子模块或 LFS 对象。Git 配置隔离，证书校验开启、重定向关闭，含凭据/查询串、非公开网段和不兼容 Windows 的路径拒绝。
- 包含与排除规则相对项目根目录，`*` 不跨目录、`**` 可跨目录。测试/示例/第三方目录默认排除，可明确包含；用户排除与敏感文件限制优先。范围规则与文件哈希一起保存。预览持有不可变快照，确认不会重新读取已变化的原目录；预览单次使用，30 分钟过期，过期临时快照启动时清理。
- 静态失败可在原项目点击“重试静态索引”，复用原快照。源码在失败后改变也不影响重试输入，旧结果保护仍然适用。

## 持久化任务队列与主动恢复

- 任务独立保存，支持运行、等待、暂停、完成、取消与失败状态。全局一个执行槽；等待任务可排序、选择任意项启动、移出队列。当前任务结束后绝不自动消费后续任务。静态索引也受同一执行槽管理，忙碌时新导入仅排队。
- 暂停会中断当前调度、保留有效批次检查点。恢复复用原任务的版本与快照，不能把已修改的原目录内容混入。取消结束本轮并清理本轮架构检查点，已有成功结果与只读快照仍可读。
- 启动恢复仅将中断运行记录为暂停，不自行继续模型请求。服务正常退出时先暂停任务；多标签保活与退出验证见下节。
- 原生静态解析改用可取消的异步子进程，暂停/超时后终止该解析进程，再释放执行槽；没有将不可取消的后台线程误报为已停止。任务进行时禁止连接测试/配置切换与另一项分析抢占执行槽。
- 检查：61 项后端测试、20 项前端测试、Ruff、TypeScript 检查和生产构建通过。覆盖并发启动、即时暂停、恢复、取消、排队排序冲突、持久化、崩溃恢复、旧结果不被暂停破坏及结束后不自动启动。

## 单实例、页面保活与解析进程生命周期

- 同一 Windows 用户与数据目录通过命名互斥锁保持单实例；重复启动使用认证本地管道取得新的一次性入口，不打开第二个数据库，也不恢复或改变任务。管道凭证使用 DPAPI，运行目录仅向当前用户授予文件权限。端口默认自动分配，显式固定端口仍支持。
- 页面分别发送心跳并保持事件连接，关闭一个页面不会使其他页面失效。最后页面断开后按 120 秒失联阈值加 60 秒宽限，暂停任务并退出；系统休眠或时钟跳变后重新给予完整宽限。新页面可使用同一浏览器会话进入，已有 AIHOT 结果仍可浏览。
- Windows Job Object 限制静态解析单任务内存为 2 GiB，并在取消、超时、关闭时结束应用自有 Python/Node 子进程树；只解析快照，不执行被分析项目。自动测试用应用自有合成进程验证子进程树终止和内存限制，不运行任何目标仓库代码。
- 实际服务验证使用独立数据目录与 `scripts/check_lifecycle.py`，没有模型请求：重复启动复用端口且中断状态哨兵不变；两个页面登记后关闭一个服务仍运行；最后页面断开 184.7 秒后退出码 0。结果位于不入 Git 的 `output/lifecycle-validation/4e1e95de-0f63-4bf8-97ad-d3953badbc7e/result.json`。开发主实例继续运行于 8125。
- 回归检查：67 项后端测试、20 项前端测试、Ruff、TypeScript 检查和生产构建通过。后台队列停止、Job Object 资源限制、睡眠/时钟跳变以及一次性凭证纳入自动检查。安装包与干净 Windows 环境尚未验收。
