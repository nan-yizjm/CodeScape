# 0.2.0 工作区与数据设计

本文件补充原开发设计，不替换 P0 基线。执行范围以用户确认的 0.2.0 收尾计划为准。

## 持久化与版本身份

cs_0004 新增 `workspace_documents`，以项目、版本、类型和键隔离文档，修订号通过 SQLite 事务比较后更新。笔记为项目级文档，保存当前关联及历史正文锚点；人工架构、操作历史、固定信息和工作区状态绑定版本。原始版本架构与源码快照不被人工调整覆盖。现有项目、学习、AI 请求和任务表保持兼容。

发布候选在同一事务迁移可靠的笔记关联、人工调整及独立工作区。笔记身份按唯一语言、路径、限定名称、签名与条件判断，允许实现变化并提示；学习进度继续按严格实现指纹迁移，两者互不代替。无法可靠匹配的笔记保留正文，人工结构冲突指向原版本。确认处理前保护该旧版。

旧源码接口保持临时读取约束；新增历史路径明确携带版本，只读其原快照。历史按记录状态、架构和快照完整性检查，不以当前源码替代。保留最近五个成功版本、固定版本、读取租约及待复核来源；分析成功后才整理超额历史。显式删除校验固定、当前、租约和修订号。清理失败保留待清理状态和可重试记录，笔记正文不因快照清理丢失。

## 增量 API

以下相对于 `/api/v1/projects/{pid}`；沿用同源身份认证、CSRF 和错误包装。版本删除沿用幂等回执，笔记与编辑使用修订校验，历史读取不会执行原始仓库。

| 路径 | 行为 |
| --- | --- |
| `GET /versions` | 版本可用性、固定、保护原因和估算空间 |
| `GET /versions/{vid}` | 历史架构、冻结学习状态、只读身份 |
| `GET /versions/{vid}/files/{file_id}` | 绑定快照的源码文本 |
| `POST /versions/{vid}/lease` | 独立视图读取租约 |
| `PUT /versions/{vid}/pin`；`DELETE /versions/{vid}` | 修订校验的固定与历史删除 |
| `GET /versions/{vid}/search` | 本地分页搜索，名称匹配优先 |
| `GET /versions/{vid}/guide` | 本地阅读建议、理由和证据 |
| `GET /notes`；`PUT /notes` | 笔记、历史锚点、关联和显式合并 |
| `POST /versions/{vid}/architecture/preview` | 归属及循环等约束校验，列出影响 |
| `PUT /versions/{vid}/architecture` | 保存、撤销、重做或恢复原始结果 |
| `GET/PUT /versions/{vid}/workspaces/{slot}` | 单页、左侧、右侧独立工作区 |
| `GET /compare?before=&after=` | 唯一源码身份的实现、归属与确认调用差异 |
| `GET /changes?remote=false` | 本地只读变化检测；远程显式选择才联网 |

## 前端行为

双侧复用同源探索器，各自有项目、版本、页面身份、租约、详情和视口。保存键包括版本与左右槽位。旧版自动抽象导航身份不直接恢复到新版分组，避免进入错误层级；真实节点和源码身份继续校验。

笔记停止输入 600ms 后保存。网络失败保留编辑器内容和当前浏览器会话草稿；重试会显式合并服务器最新内容。已成功保存的笔记持久化于数据库，可跨重启；未成功保存的会话草稿不承诺浏览器完全关闭后的恢复。正文纯文本显示，不执行 HTML。

阅读分组优先依据确认协作，其余按源码邻近提供有界导航，明确标为阅读辅助；不能把分组当作额外 AI 判断。有效架构保证可见函数恰好归属一次、层级无循环，人工层不产生自定义关系。依赖按原调用证据重新聚合，正交端口与完整导出沿用既有约束。

差异不强行配对同名或歧义实体；模块名称集合变化和人工调整单独标识。源码检查使用发布时范围与排除规则，在项目打开、页面前台及每 60 秒检查；失效目录、范围变化和检查失败分别说明，不自动分析、拉取或合并。
