## 可直接运行的检查

复制最新便携包和 `packaging/Test-CleanWindows.ps1` 至测试机器，解压便携包。脚本不要求安装 Python、Node、Git 或编译器，使用 Windows 自带 PowerShell 5.1；只在独立用户临时目录生成四语言静态样例与应用数据，不执行样例，不读取已有项目，不需要密钥，不发模型请求，不改变系统网络或环境变量。

```powershell
powershell.exe -NoProfile -NonInteractive -File C:\验收\Test-CleanWindows.ps1 -Executable C:\验收\CodeScape\CodeScape.exe -EnvironmentKind CleanWin11
```

Windows 10 使用 `CleanWin10`；开发机使用默认的 `Developer`。环境参数只是操作者声明，不自动证明系统干净。记录虚拟机镜像来源、系统版本、安装的软件清单和运行前快照，以支持环境判定。

脚本核对制品文件清单，移除测试子进程的开发工具 PATH，验证独立启动、预置样例标识、8 个四语言函数及确认调用、未授权静态结果标识、原样例字节、学习保存、正常退出及重开读取源码。结束时打印独立报告路径，保留数据供复核。通过状态为“自动步骤通过，待人工界面与环境验收”；失败时返回非零，不把失败项记作通过。

## 必须实际操作的环境项

| 环境与动作 | 验收依据 | 当前状态 |
|---|---|---|
| 干净 Windows 10 与 Windows 11 分别运行 | 两份自动报告、镜像来源、系统与软件清单、实际界面截图 | 未实测；用户免除本轮门槛 |
| 首次安装、运行中升级、卸载 | 安装/卸载记录；升级前后学习与快照一致，运行中先正常保存退出；卸载保留应用数据 | 开发机已测，干净系统未测 |
| 跨正式版本升级 | 两个不同正式版本的实际安装与数据保留记录 | 当前均 0.1.0，只完成跨预发布构建 |
| 真实系统断网后重开 | 先保存分析，再在专用测试机断网；新开页面可阅读、定位源码及保存学习状态；联网失败不替换成功版本 | 已测应用进程 DNS/TCP 阻断，系统断网未测 |
| 真实系统休眠与主动恢复 | 在专用测试机使用已授权样例开始分析，休眠/唤醒后核对任务、检查点和用量；主动恢复仍读取原快照，不能自动继续模型请求 | 已测时钟跳变与真实进程退出，系统休眠未测 |

断网、休眠和安装升级使用专用测试环境，记录动作、时间、构建号、结果和复现步骤。脚本不会自动改变正在工作的主机网络或休眠状态。
