# CodeScape · 源境

从语义模块进入函数图，再沿真实调用证据阅读只读源码，记录自己的学习状态。

当前版本是 **v0.1.0 / P0 最终开发候选**，以 `v0.1.0-p0.1` 作为第一版开发留档，安装包、便携包和源码见 [GitHub 留档版本](https://github.com/nan-yizjm/CodeScape/releases/tag/v0.1.0-p0.1)。35 项验收已验证，AC-29 的开发复核通过，最后用户理解验收待确认；四个公开仓库的全范围评测未全部完成。完整需求见 [PRD](docs/CodeScape_PRD.md)，实施基线见 [开发设计](docs/CodeScape_Development_Design.md)，逐项状态见 [P0 验收追踪](docs/reports/p0/P0验收追踪.md)，实际证据见 [开发与验收记录](docs/reports/p0/开发与验收记录.md)。本轮用户已按 CHG-13 免除干净 Windows 10/11 环境门槛，不能将自动检查通过视为全部 P0 完成。留档范围和制品校验见 [第一版版本说明](docs/releases/v0.1.0-p0.md)。

## 本轮可用功能

- 本地目录或公开 Git 默认分支导入，先预览范围再确认；创建独立源码快照，记录 Commit、包含/排除规则和文件哈希。
- Python AST、TypeScript Compiler API、C/C++ Tree-sitter 与 libclang 基础静态解析。
- 纵向模块架构、两层父子模块嵌套、大型项目源码域抽象与逐层展开、返回上一级和恢复同级模块；函数画布保留本模块函数，其他模块保持收起。
- 递归边、同向调用证据聚合、全屏探索、阅读尺寸与自适应缩放。
- 单侧详情面板、只读全文源码、行范围高亮、当前层级完整 SVG 导出。
- SQLite 保存学习状态和各层级画布位置，修订号防止同时操作互相覆盖。
- 手动重新扫描项目形成独立候选，新架构通过校验后事务发布；按唯一身份和实现指纹迁移函数学习状态，失败/取消保留旧结果。
- 持久化单任务队列，等待排序、主动启动、暂停/检查点恢复、取消；任务完成后不自动继续下一项。
- 项目删除前二次确认范围；停止该项目任务和新读取，清理软件保存的数据；文件占用保留失败记录并支持重试，原始源码不变。
- 同一用户与数据目录只启动一个服务；自动选择空闲端口，多页面独立保活，最后页面断开后保存任务并退出。
- DeepSeek / 兼容 Chat Completions 接口、可选受控流式接收；Windows DPAPI 保存密钥；模型 JSON、实体归属与实际补读源码证据校验。
- 受控分批分析、快照内只读补读、预生成函数讲解、全局简明概览；保留真实作用域、静态/AI 来源和目标冲突证据。
- 有源码依据的主要协作筛选、模块邻居预览、大图视口绘制；导出仍包含完整当前投影。
- C/C++ 可信系统声明、只读编译数据库、多配置一致性、模板与宏双位置证据；受限 pybind11 接口仅展示模块协作。
- 原生解析超时后保留语法索引并明确缺口；页面资源缺失时给出中文恢复提示。
- AI 请求账本记录实际尝试、阶段、接收端、成功/失败及远端未知状态；缺少用量或价格时显示未知，账本不保存正文和密钥。
- 发送项目源码前，明确展示接收端、模型和范围；无源码连接测试独立提供。

预置样例包含三个文件、八个函数。它的初始模块和概览为**人工预置**，调用关系是实际静态提取。真实 DeepSeek 联调结果另存于 [验证记录](docs/reports/m0/deepseek-validation.json)，不会拿人工模块冒充 AI 分析结果。

## Windows 开发运行

需要 Windows、Python 3.12、Node.js 22.12+ 或 24，以及 uv。当前主机已准备好依赖和前端构建，可直接运行 `Start-CodeScape.ps1`。

首次从仓库准备环境：

```powershell
uv sync --frozen
npm ci
npm run build
```

启动：

```powershell
.\Start-CodeScape.ps1
```

启动脚本使用项目自己的 `.venv`，在 `127.0.0.1` 自动选择空闲端口，打开包含一次性启动凭证的浏览器入口。需要固定端口时使用 `-Port 8125`。重复启动复用已有服务并取得新的入口，不会重新初始化任务。Ctrl+C 可停止服务。最后一个页面断开后，等待 120 秒心跳失联阈值和 60 秒保存宽限，再暂停任务并退出；休眠唤醒重新给予宽限。不要将开发服务暴露到外网。

数据默认位于 `%LOCALAPPDATA%\CodeScape`，不进入 Git。可以在启动前设置 `CODESCAPE_DATA_DIR` 使用独立开发数据目录。程序不执行被导入项目的代码、安装、构建或测试。

本地实例凭证由当前用户 DPAPI 加密，运行目录使用当前用户权限。静态解析子进程由 Windows Job Object 管理，单任务内存上限 2 GiB；取消、超时或服务退出会终止该进程及其子进程。该机制用于资源与生命周期管理，不是执行用户源码的沙箱。

配置 AI 时点击右上角设置，填写服务地址、模型和 API Key。默认接收端为 `https://api.deepseek.com`；保留 DeepSeek 主要适配。当前用户指定的评测接收端为 `https://www.cctq.ai/v1`、模型为 `gpt-6.1-sol`，历史模型结果按原身份保留。密钥不写入 `.env`，不进入命令行参数或日志。兼容服务需提供 `/chat/completions` 与 JSON 对象输出；启用流式接收时还需兼容 SSE 完成原因、`[DONE]` 和用量事件。流式片段收齐后仍统一校验，异常流或缺失结束标记不会发布部分响应。

## 开发检查

```powershell
.venv\Scripts\ruff.exe check server scripts tests
.venv\Scripts\pytest.exe -q
npm run typecheck
npm test
npm run build
npm audit
```

测试运行 CodeScape 本身；`tests/fixtures` 中的项目只作为解析输入，禁止执行。真实模型测试与离线固定响应测试分开记录，不在常规测试中产生 API 费用。`scripts/verify_ai.py` 固定仅发送已授权的三个预置样例，运行前仍应确认当前授权与服务配置。

## 当前边界

AI 分析按文件和行范围拆成受控批次，保存逐批检查点，校验归属和源码引用后合并架构；跨批模块边界明确标记需复核。每单元最多 6 次模型尝试，补读最多 3 轮、每轮 4 项，不能执行指令或访问任意路径。函数讲解在分析阶段生成，普通阅读不请求模型。引用有效仍不保证语义正确；受限递归聚合事实用于拦截已知矛盾，真实质量另行核对。

重新扫描创建独立候选，恢复仍绑定原候选。活动页面以短期读取租约保护旧版本；过期页面不能重新取得旧版本，已开始的读取完成后回收为墓碑，旧版本最长保留读取授权 120 秒。C/C++ 仅读取快照中的编译元数据和校验后的应用自有声明，关闭解析器文件系统回退。条件、依赖、宏位置或多配置目标不能确认时，不画猜测边。原生工作进程未完成时保留语法实体并标记本轮语义未完成，不冒充 AI 架构成功。

目前仅支持不带 BOM 的 UTF-8 源码。预发布包未签名；开发机 Windows 11 的独立运行、安装、跨预发布构建升级、不兼容数据拒绝和卸载保留数据已测，未运行的干净 Windows 10/11 或跨正式版本条件不声称通过；本轮用户已免除干净环境矩阵，现有实际跨构建升级用于升级功能验收。[独立环境验收](docs/P0_独立环境验收.md)提供可用 Windows 自带 PowerShell 5.1 运行的检查脚本，实跑结果明确标记开发机。四个固定公开样本的约定范围已获当前接收端上传授权，完整模型质量与同流水线范围对照仍未通过；该授权不扩展到 AIHOT 或其他源码。动态分派和其他跨语言机制保留局限。

探索层级、同级开关、视口、详情返回栈与阅读位置保存在本地，多个页面写入冲突时提示载入已保存记录。函数层可恢复当前外层模块的同级模块。

有可读代码但没有可见函数的叶模块可独立记录学习状态；空模块与不完整占位不进入完成率。普通注释和排版变化按实现指纹保留进度，职责或范围变化保守重置。

本地数据库升级前通过 SQLite 建立技术恢复副本并执行 Alembic 迁移；失败停止启动并恢复原库。损坏或来自更新版本的数据不会被空库或降级替代。
